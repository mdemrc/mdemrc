## ⚡ About Me

Computer Engineering student building production-grade full-stack platforms end to end — from database schema and admin tooling to payment flows and front-end. I don't write code to learn a framework; I ship working systems that real users (and real clients) operate every day.

* 🛠 **Daily stack:** `Next.js` / `React` / `Node.js` / `Express` / `Prisma` / `TypeScript`
* 🐍 **Automation:** `Python`, `Selenium`, `Flask` — browser automation, OTP relays, ingestion pipelines
* 🐘 **PHP roots:** `PHP 8` + `MySQL` for legacy projects and self-hosted utilities
* 🐧 **Operations:** Linux, Docker, Nginx, VPS deployment — I run what I build
* 🎯 **Mindset:** Practical debugging, real-world product thinking, and shipping over polishing
